# Bao restaurant · Gala X Ci

Live scene: https://galaxci.com/galaxci/bao/

Interactive 3D Gaussian Splatting reconstruction by Ci Song, trained from 19 registered 360° panoramas for 16,000 steps with Spirula Studio. Contains 997,248 Gaussians with SH3 colors. The quantized SPZ v3 export is ~22 MB; the original full-precision PLY remains archived locally.

Drag to look around; WASD to move; Q/E to change height; R to reset. Preset buttons return to capture positions. Touch controls are included. WebGL2 is required.

Everything required to view the scene is served statically from this directory. No local API, CDN, account, or external drive is required. Rendering library licenses are in LICENSES.txt. Model metadata and checksums are in model-info.json.
