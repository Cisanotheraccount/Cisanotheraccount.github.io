# ShotFlow presentation derivatives

These files provide subtitle-free playback and case imagery from the existing Reference Study captures. The two original Photos-library previews are intentionally retained unchanged. Original captures, source footage and analysis output remain unchanged. App UI and guide text are English. Only real shots 5, 6 and 7 are playable; the complete 32-shot result is preserved.

Video derivatives retain the original cut boundaries, frame timestamps and original AAC audio packets. Subtitle pixels were cleared only inside the bottom black letterbox; no subject crop or zoom was applied. Static image derivatives retain native dimensions and all pixels outside their recorded edit regions. The approved Photos-preview exception is recorded in provenance.

The analysis recording is unchanged. Its approximately three-second duration is editorial demo timing, not analysis performance. The web guide does not run the native application or analyze visitor uploads.
